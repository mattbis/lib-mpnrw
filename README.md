# lib-mpnrw

A small class to use for a earth centric celestial transformation to provide a universal address for any location on earth.

## Transform model 2

Both packages identify the corrected transform with major version 2. Store the model version, UTC instant, geodetic inputs, origin and Earth orientation with a derived address. To reproduce an address generated by version 1, use the original release or commit.

Latitude and longitude are WGS84 degrees east/north (latitude first, positive north). Height is metres above the ellipsoid. Output is a position in metres on approximate mean J2000 equatorial axes. Pass a zero offset for an Earth-centred result. For a translated origin, supply the vector from that origin to Earth's centre on the same axes, in metres. For a Sun-centred example:

```js
const date = new Date('2026-03-20T12:00:00.250Z')
const earth = engine.get_heliocentric_earth_m(engine.get_julian_date(date))
const site = engine.get_universal_address(51.1789, -1.8262, 103, date, earth)
```

The example uses UTC as an approximation to TT and UT1. JavaScript accepts an optional sixth argument with `dut1` (UT1 minus UTC in seconds), `tt_minus_utc` (seconds), and `xp`, `yp` (IERS pole coordinates in radians). Each defaults to zero. With supplied offsets, pass TT Julian Date to the heliocentric helper. BigInt uses Q.80 for all these fields and vectors, and accepts a Date or integer Unix milliseconds for the instant. Rust provides `get_universal_address_ms` with Unix milliseconds and an `EarthOrientation` value. The calendar entry point accepts whole seconds.

The model uses linear precession, four nutation terms, GMST and first-order polar motion. The effective nutation matrix includes the first-order cancellation of the equation of the equinoxes when paired with GMST. The legacy Sun helper returns an approximate Earth-to-Sun vector in kilometres on equatorial axes of date. The heliocentric helper reverses it, converts to metres and precesses to J2000. The SOFA test case at MJD 53736 checks a single Earth-centred vector to 10 metres. Accuracy at other epochs and heliocentric ephemeris accuracy require separate validation.
